# Bangla LLM Hallucination Detection

A traditional NLP and machine learning project for detecting hallucinated responses generated by Large Language Models (LLMs) in Bangla.

#Project Overview

This project aims to classify Bangla LLM responses as either **faithful** or **hallucinated** by comparing them with reliable reference information.

The project uses traditional NLP techniques to convert text into numerical features and applies machine learning classifiers to identify unsupported or incorrect responses.

## Methodology

The project follows these main steps:

1. Bangla question-answer dataset preparation
2. Dataset exploration and preprocessing
3. Reference answer and LLM-generated answer comparison
4. Text preprocessing and feature extraction
5. Bag of Words (BoW) and TF-IDF representation
6. Train-test data splitting
7. Machine learning classification
8. Model evaluation and comparison

## Text Representation

Two text representation techniques were used:

- **Bag of Words (BoW)**
- **TF-IDF (Term Frequency-Inverse Document Frequency)**

## Machine Learning Models

The following traditional machine learning algorithms were evaluated:

- Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

The performance of BoW and TF-IDF representations was also compared to identify the better-performing approach.

## Implementation

The complete project was implemented in **R**.

### Main Technologies

- R
- Natural Language Processing (NLP)
- Machine Learning
- Bag of Words
- TF-IDF
- Naive Bayes
- Logistic Regression
- Support Vector Machine

## Project Goal

The main goal is to explore how effectively traditional NLP and machine learning methods can distinguish between evidence-supported and hallucinated Bangla LLM responses.
